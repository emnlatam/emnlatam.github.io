# Salamander Grand Piano samples

Piano samples for `/sight-melody` (trial bank, selected by `PIANO_BANK` in `_layouts/emn/sight-melody.html`).

- Source: Salamander Grand Piano V3 by Alexander Holm, https://sfzinstruments.github.io/pianos/salamander (mirrored at https://tonejs.github.io/audio/salamander/)
- License: Creative Commons Attribution 3.0 (https://creativecommons.org/licenses/by/3.0/). Attribution is kept here and must stay with the files.
- Files are sampled every minor third (C, D#, F#, A). The page plays the nearest sample and pitch-shifts it for the in-between keys.
